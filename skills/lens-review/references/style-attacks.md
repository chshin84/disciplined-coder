# 문체 공격 항목

독자 렌즈(`lens-readability`)가 공격할 문체 항목과, 그 지적을 거를 때 쓰는 판정 기준점과 과잉 지적 반례를 둔다. `lens-review` 가 이 파일을 독자 렌즈에 `CRITERIA` 로 넘기고, 1차 디펜스에서 독자 렌즈의 지적을 거를 때도 연다. 항목은 사용자가 지적한 AI 티 문체에서 왔다. 금지 낱말 목록은 `korean-banned-words.md` 가 소유하므로 여기서 낱말을 늘어놓지 않는다.

## 공격 항목

지적마다 해당 항목 이름을 `why` 첫머리에 적어라.

| 항목 | 설명 |
|---|---|
| 직역투 | 영어 문장 구조를 옮긴 문장이다. 무생물 주어와 타동사, `~를 통해`·`~에 대한`, 이중 피동, 영어 단어를 고유어로 옮겨 한국어에 없던 말이 된 표현이 해당한다 |
| 어울리지 않는 고유어 | 쉬운 말로 쓰려다 업무 문서에서 쓰는 한자어를 고유어로 바꿔 어색해진 말이다(`담다` 대신 `포함하다`, `더하다` 대신 `추가하다`) |
| 평소 안 쓰는 말 | 뜻은 맞지만 업무 문서와 기사에서 드물게 쓰여 읽는 사람이 멈추는 말이다(`정본` 대신 `원본`) |
| 뜻 없는 단위·차수 | 무엇을 세는지 밝히지 않은 단위나 차수다(`넷째 판`, `회차`). 무엇의 몇 번째인지 이름과 함께 적어야 한다 |
| 대명사처럼 쓰는 말 | 대상의 이름 대신 `것`·`일`이나 수사(`이 셋`)로 받는 말이다 |
| 얼버무림 | 결론을 또렷하게 적지 않고 흐린 말끝이다. 단정하거나 명사구로 적어야 한다 |
| 비유 | 대상의 이름과 실제 동작 대신 쓴 비유다 |
| 내부 맥락·용어 | 작성자만 아는 맥락이나 내부 용어를 풀지 않고 쓴 문장이다. 앞뒤 설명 없이 선택지만 내미는 문장도, 표와 예시가 있지만 용어를 풀지 않은 문장도 해당한다 |
| 장황함·묻지 않은 답 | 묻지 않은 내용이나 같은 말의 반복 때문에 답이 묻히는 곳이다 |
| 톤 없는 정보 교환체 | 읽는 사람과 문서 종류에 맞는 어투가 아니라 작업 정보를 주고받는 메모 말투로 쓴 글이다. 정보가 정확해도 읽히지 않으면 전달되지 않는다 |
| 형식 | 같은 종류를 늘어놓지 않는 불릿, 명사구가 아닌 목차와 표 머리(`확인할 것` 대신 `확인사항`), 개수를 붙인 제목, 구어로 끝을 알리는 문구다 |

## 판정 기준점

사용자가 답을 판독할 때 고른 기준이다. 렌즈는 지적을 올리기 전에, 메인 세션은 1차 디펜스에서 이 기준으로 지적을 거른다.

| 기준점 | 판정 |
|---|---|
| 나아졌으면 통과 | 비교할 원문이 있으면 원문보다 나아졌는지로 판정한다. 완벽하지 않아도 나아졌으면 통과다 |
| 나중에 되물은 세부는 기준 아님 | 읽는 사람이 나중에 따로 물을 세부가 빠진 문장은 위반으로 보지 않는다 |
| 전체가 자연스러우면 통과 | 글 전체가 자연스럽게 읽히면 공격 항목에 해당하는 문장이 몇 개 있어도 통과다 |
| 내부 용어를 풀지 않았거나 장황해 답이 묻히면 위반 | 표와 예시가 있어도 이 조건이면 위반이다 |
| 지적이 겨눈 문장만 | 지적은 문제 문장만 겨누고, 그 문장 밖의 고칠 곳을 끌어오지 않는다 |

## 과잉 지적 반례

렌즈가 공격 자세로 읽을 때 지나치게 지적하는 형태다. 아래에 해당하는 지적은 디펜스에서 기각한다.

- 글 전체가 자연스러우면 공격 항목에 해당하는 문장이 있어도 지적하지 않는다. 사용자는 렌즈가 위반으로 본 문체를 자연스럽다며 통과로 판정한 적이 있다.
- 업무 문서와 기사에서 흔히 쓰는 표현은 직역투로 보지 않는다. 결과나 자료를 주어로 두고 '보여준다'로 맺는 문장이 그 예다.
- 업계 표준 용어와 영어 원어가 표준인 용어는 바꾸라고 지적하지 않는다.
