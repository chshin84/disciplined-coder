# 문체 공격 항목

독자 렌즈(`lens-readability`)가 잡아낼 문체 항목과 지적을 거를 판정 기준점, 과잉 지적 반례를 정리했다. `lens-review`는 이 파일을 `CRITERIA`로 독자 렌즈에 넘기고, 1차 디펜스에서 독자 렌즈의 지적을 추릴 때도 연다. 항목은 사용자가 지적한 AI 티 문체에서 뽑았다. 금지 낱말 목록은 `korean-banned-words.md` 가 소유하므로 여기서 낱말을 늘어놓지 않는다.

## 공격 항목

지적할 때마다 해당 항목 이름을 `why` 맨 앞에 적어라.

| 항목 | 설명 |
|---|---|
| 직역투 | 영어식 문장 구조를 옮겨 쓴 표현이다. 무생물 주어와 타동사, `~를 통해`·`~에 대한`, 이중 피동, 영어 단어를 고유어로 옮겨 한국어에 없는 말이 된 표현을 잡는다 |
| 어울리지 않는 고유어 | 쉽게 풀려다 업무 문서용 한자어를 고유어로 바꿔 어색해진 표현이다(`담다` 대신 `포함하다`, `더하다` 대신 `추가하다`) |
| 평소 안 쓰는 말 | 뜻은 맞지만 업무 문서나 기사에서 잘 쓰지 않아 독자가 멈칫하는 말이다(`정본` 대신 `원본`) |
| 뜻 없는 단위·차수 | 세는 대상을 밝히지 않은 단위나 차수다(`넷째 판`, `회차`). 무엇의 몇 번째인지 대상 이름을 붙여 적어야 한다 |
| 대명사처럼 쓰는 말 | 대상 이름 대신 `것`·`일`이나 수사(`이 셋`)로 가리키는 말이다 |
| 얼버무림 | 결론을 분명히 밝히지 않고 흐린 말끝이다. 단정하거나 명사구로 맺어야 한다 |
| 비유 | 대상 이름과 실제 동작 대신 에둘러 쓴 비유다 |
| 내부 맥락·용어 | 글쓴이만 아는 맥락이나 내부 용어를 풀지 않고 쓴 문장이다. 앞뒤 설명 없이 선택지만 던지거나, 표와 예시를 달고도 용어를 설명하지 않은 문장을 잡는다 |
| 장황함·묻지 않은 답 | 묻지 않은 내용이나 같은 말 되풀이로 답이 묻히는 대목이다 |
| 톤 없는 정보 교환체 | 독자와 문서 종류에 맞는 어투 대신 작업 정보를 주고받는 메모 말투로 쓴 글이다. 정보가 정확해도 읽히지 않으면 뜻이 전해지지 않는다 |
| 형식 | 독자의 읽기 흐름을 끊는 형식이다. 성격이 다른 항목을 섞은 불릿, 명사구가 아닌 목차와 표 머리(`확인할 것` 대신 `확인사항`), 개수를 붙인 제목, 구어로 끝을 알리는 문구를 잡는다. 지정한 양식·스키마·제목 규칙 준수 여부는 대조 렌즈의 형식 계약 검사 몫이므로 여기서는 보지 않는다 |

## 판정 기준점

사용자가 답을 평가할 때 고른 기준이다. 렌즈는 지적을 올리기 전에, 메인 세션은 1차 디펜스에서 이 기준으로 지적을 추린다.

| 기준점 | 판정 |
|---|---|
| 나아졌으면 통과 | 비교할 원문이 있으면 원문보다 나아졌는지만 본다. 완벽하지 않아도 나아졌으면 통과시킨다 |
| 나중에 되물은 세부는 기준 아님 | 독자가 나중에 따로 물을 세부가 빠져도 위반으로 잡지 않는다 |
| 전체가 자연스러우면 통과 | 글 전체가 자연스럽게 읽히면 공격 항목에 해당하는 문장이 몇 개 있어도 통과시킨다 |
| 내부 용어를 풀지 않았거나 장황해 답이 묻히면 위반 | 표나 예시를 달았어도 이 조건이면 위반으로 본다 |
| 지적이 겨눈 문장만 | 문제 문장만 겨누고, 그 밖의 고칠 곳은 끌어오지 않는다 |

## 과잉 지적 반례

렌즈가 공격 자세로 읽다가 지나치게 지적하는 사례다. 아래에 해당하는 지적은 디펜스에서 기각하라.

- 글 전체가 자연스럽다면 공격 항목에 해당하는 문장이 있어도 지적하지 마라. 렌즈가 위반으로 잡은 문체를 사용자가 자연스럽다며 통과시킨 적이 있다.
- 업무 문서나 기사에서 흔히 쓰는 표현은 직역투로 잡지 마라. 결과나 자료를 주어로 두고 '보여준다'로 맺는 문장이 대표적이다.
- 업계 표준 용어와 영어 원어가 표준인 용어는 고치라고 지적하지 마라.
