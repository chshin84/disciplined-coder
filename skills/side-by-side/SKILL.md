# side-by-side — 두 글을 좌우로 비교하는 페이지

변경 전후 문서, 같은 질문의 두 답, 한 파일의 두 버전을 좌우로 배치한 HTML 페이지를 만들어 열어라. 사용자에게 답의 판독을 받는 판독 페이지도 이 형식에 판정 칸을 붙인 페이지다.

## 출력 위치

기본 출력은 로컬 HTML 파일이다. claude.ai 아티팩트로 올리지 말고 PC에 저장해 브라우저로 열어라(윈도우는 `start`). 집처럼 그 PC 밖에서 보려고 사용자가 아티팩트를 요청할 때만 아티팩트로 올려라.

파일은 프로젝트가 정한 gitignore 폴더(디시플린코더 저장소는 docs/html-reports 폴더)에 저장하라. 정해진 폴더가 없으면 세션 임시 폴더에 둬라. 실제 대화나 사내 자료가 포함된 페이지는 저장소에 커밋하지 마라. 재현 시험 판독 페이지는 실제 대화 원문이 들었으므로 docs/html-reports 폴더 대신 `%USERPROFILE%\.dc-eval\` 아래 판정 폴더에 둬라(`scripts/eval_replay_report.sh`가 그 폴더에 만든다).

## 판독 페이지 형식

판독 페이지 형식은 여기가 소유한다. 판독 페이지 생성 스크립트와 형식을 언급하는 문서는 이 절을 참조한다. 판정 칸이 없는 단순 비교 페이지는 좌우 배치·마크다운 렌더링·대화 말풍선 항목만 따른다.

- 두 글을 좌우에 나란히 배치하고 두 칸의 스크롤을 연동하라. 화면이 좁으면 위아래로 쌓아라.
- 모델의 답변 원문은 마크다운으로 렌더링하라. 생성한 HTML은 페이지에 넣기 전에 정화하라(예: 버전을 고정한 `marked`와 `DOMPurify`를 쓴다).
- 그때 사용자가 보낸 메시지는 대화 말풍선으로 표시하라.
- 사용자가 지적한 문장과 판정자가 근거로 삼은 문장을 서로 다른 색으로 형광 표시하라. 판정자가 근거 문장을 원문 그대로 반환하게 하라. 원문에서 찾지 못한 근거 문장은 페이지에 찾지 못했다고 적어라.
- Claude의 판정, 개선 점수, 근거를 두 답보다 위에 표시하라. 점수는 "B 가 A 보다 많이 나빠짐 −2 ~ 많이 나아짐 +2" 다섯 단계다.
- 사용자가 판정이 틀린 쌍만 같은 다섯 단계로 수정하게 하라. 수정한 값은 브라우저 저장소에 남기고 복사 버튼으로 JSON을 Claude에게 전달하게 하라.

사용자 판독이 판정과 다르면 사용자 판독을 따른다.
