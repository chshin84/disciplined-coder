# side-by-side — 두 글을 좌우로 비교하는 페이지

두 글(변경 전후의 문서, 같은 질문에 대한 두 답, 한 파일의 두 버전)을 좌우에 나란히 둔 HTML 페이지를 만들어 열어라. 사용자에게 답의 판독을 받는 판독 페이지도 같은 형식에 판정 칸을 추가한 페이지다.

## 출력 위치

기본은 로컬 HTML 파일이다. claude.ai 아티팩트로 올리지 말고 PC 에 파일로 만들어 브라우저로 열어라(윈도우는 `start`). 사용자가 집처럼 그 PC 밖에서 보려고 아티팩트를 요청할 때만 아티팩트로 올려라.

파일은 프로젝트가 정한 gitignore 폴더(디시플린코더 저장소는 docs/html-reports 폴더)에 두고, 정한 폴더가 없으면 세션의 임시 폴더에 둬라. 실제 대화나 사내 자료가 든 페이지는 저장소에 커밋하지 마라.

## 판독 페이지 형식

판독 페이지 형식은 여기가 소유한다. 판독 페이지를 만드는 스크립트와 그 형식을 언급하는 문서는 이 절을 가리킨다. 판정 칸이 없는 단순 비교 페이지는 앞의 세 항목만 따른다.

- 두 글을 왼쪽·오른쪽에 나란히 두고, 두 칸이 함께 스크롤되게 하라. 좁은 화면에서는 위아래로 쌓아라.
- 모델 답 원문은 마크다운으로 렌더링하라. 렌더링한 HTML 은 삽입 전에 정화하라(예: `marked` 와 `DOMPurify` 를 버전을 고정해 싣는다).
- 당시 사용자 메시지는 대화 말풍선으로 보여라.
- 사용자 지적이 겨눈 문장과 판정자가 근거로 든 문장을 서로 다른 색으로 형광 표시하라. 판정자에게는 근거 문장을 원문 그대로 돌려주게 하고, 원문에서 찾지 못한 근거 문장은 페이지에 찾지 못했다고 적어라.
- Claude 의 판정과 개선 점수와 근거를 두 답보다 먼저 보여라. 점수는 "B 가 A 보다 많이 나빠짐 −2 ~ 많이 나아짐 +2" 의 다섯 단계다.
- 사용자는 판정이 틀린 쌍만 같은 다섯 단계로 고치게 하라. 고친 값은 브라우저 저장소에 보관하고, 복사 버튼으로 JSON 을 Claude 에게 넘기게 하라.

판독이 판정과 다르면 사용자 판독을 따른다.
