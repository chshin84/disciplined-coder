같은 spec 「측정」 절에 불릿 목록 써 줘. 개정한 스킬로 큰 개발을 한 번 끝낼 때마다 결정 기록에 남길 값들이야.

- 워크스트림 수
- 시험 병합 횟수, 그중 실패한 횟수 → 실패 수는 워크스트림 수와 같이 봐야 함(워크스트림 많으면 당연히 늘어남)
- 토큰: 현재 세션이 쓴 것, 서브 세션들이 쓴 것 따로. 이것도 워크스트림 수랑 같이 봐야 의미 있음
- 리뷰 차수별 🔴 지적 수
- 사용자가 개입한 횟수(질문 받은 수)
