선행연구 에이전트 spec 「리서치 근거」 끝에, 선행 사례에서 무엇을 가져왔는지 정리하는 문단 써 줘.

- Anthropic 의 multi-agent research system 글: 서브에이전트 결과를 메인 컨텍스트에 다 쌓으면 넘친다고 함 → 우리는 워크플로 스크립트가 중간 결과를 변수에 두고, 검증을 통과한 항목만 메인 세션에 넘김
- 인용 검증: 연구자의 자기 보고를 믿지 않음. 별도 검증자가 원문을 열어 판정
- 탐색 이중화: 같은 하위 질문을 연구자 둘에게 맡겨 교차 확인하는 사례가 있음 → 우리는 기본으로 끄고, 사용자가 원할 때만 켬(2026-10-18 사용자 결정)
- 참신성 점수: 몇몇 도구가 참신성을 점수로 매김 → 우리는 채점 안 함. 기시감·결말 같은 체크리스트로만 판정
