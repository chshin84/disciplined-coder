성공: 어느 문장에서도 연결어미 바로 뒤 쉼표가 한 번 이하다. 이어지는 동작(서브 세션 이어 쓰기, 병합 전 대조, git 에서 진행 위치 도출)이 많으면 문장을 나누거나 명사 나열로 쓴다.
실패: 한 문장 안에 연결어미(-고, -며, -면, -는데, -어 등) 바로 뒤 쉼표가 두 번 이상 나온다(예: '…이어 쓰고, …대조하며, …도출한다'). 명사를 늘어놓는 쉼표와 '예를 들어,' 같은 이어주는 말 뒤 쉼표는 세지 않는다.
