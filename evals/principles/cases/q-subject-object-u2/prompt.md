[이전 대화]
사용자: 대시보드에 '데이터 수정 요청' 기능 넣는 spec 쓰는 중이야. 처리 흐름 절 써 줘. 대충 이래.
- 요청 등록
- 한도 넘으면 자동 반려
- 승인
- 반영
- 반영 결과 알림
- 이의 있으면 재검토
작업 기록(사용자와 합의한 내용):
- 운용역이 대시보드 화면에서 수정 요청을 등록한다.
- 대시보드 서버의 검증 모듈 rulecheck 가 금액이 1억 원 한도를 넘는 요청을 자동으로 반려한다. 한도 값은 config/limits.yaml 에 있다.
- 한도 안의 요청은 운용지원팀장이 승인하거나 반려한다.
- 승인된 요청은 야간 배치 KESTREL 이 다음 날 02시에 DB 에 반영한다.
- 반영 결과 알림은 KESTREL 이 요청한 운용역에게 메신저로 보낸다.
- 이의 신청의 재검토 주체는 아직 정하지 않았다.
