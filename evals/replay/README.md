# 재현 시험

세션에 실리는 지시(원칙, 금지어 상시 보기, 매 턴 리마인더, 훅이 Claude 에게 보내는 글, 스킬·에이전트 description)를 바꿀 때, 실제 대화를 사용자 메시지 직전까지 재개해 두 조건으로 답을 한 번씩 만들고 판정자가 두 답을 비교한다. 설계는 `docs/superpowers/specs/2026-11-13-v2-rebuild-design.md` 「시험 체계」에 있다.

이 폴더에는 턴 ID 목록(`turns-<이름>.txt`, 숫자 한 줄씩)과 이 안내만 둔다. 대화 원문·답·판정·판독 페이지는 공개 저장소에 넣지 않고 `%USERPROFILE%\.dc-eval\` 에 둔다. `scripts/test_replay.sh` 가 이 폴더에 비밀 패턴과 숫자 밖의 줄이 없는지 검사한다.

## 조건

조건 이름이 원칙·금지어·리마인더를 가져올 커밋을 정한다. 정의의 원본은 `scripts/_replay.py` 머리 주석이다.

| 조건 | 설정 CLAUDE.md 와 리마인더 |
|---|---|
| `v1` | 태그 `archive/v1-final` 의 원칙, 원본 금지어 표, 그 커밋의 리마인더 |
| `v2.<n>` | `%USERPROFILE%\.dc-eval\replay\V2_REV.<n>.txt` 가 적은 커밋의 원칙, 금지어 상시 보기, 리마인더 |
| `v2.<n>-table` | `v2.<n>` 과 같고 금지어만 원본 표 |
| `<조건>-tools` | 같은 지시에 읽기 전용 도구(Read·Grep·Glob)와 턴 시각 직전 저장소 사본을 준다 |

모든 조건의 CLAUDE.md 앞에는 실제 PC 전역 지시를 붙인다. 그 파일 경로는 환경 변수 `DC_EVAL_BASE_MD` 로 넘기고, 넘기지 않으면 붙이지 않는다. 도구 없는 조건은 출력 스타일 Concise 에 "도구 없이 답을 끝까지 써라" 한 줄을 추가한다.

## 판정 지시

판정 질문의 원문은 `scripts/_judge.py` 의 `PROMPT_CORR`(지적 턴)와 `PROMPT_NONE`(지적 없던 턴)이고, 두 질문이 함께 쓰는 판정 기준점 5개는 `CRITERIA` 다. 지적 턴은 당시 사용자 지적과 그 요지를, 지적 없던 턴은 사용자 원문 요구 "진행해라고 하면 진행하고, 물어보면 물어본 것만 답변하고" 를 기준으로 쓴다.

판정자는 같은 턴의 두 답을 A·B 순서를 바꿔 두 번 −2~+2 로 매기고 근거 문장을 원문 그대로 돌려준다. 두 점수가 모두 0 이상이고 평균이 0 보다 크면 개선, 모두 0 이하이고 평균이 0 보다 작으면 악화, 나머지는 같음이다. 참고 지표는 위반 판정, 답 길이 중간값, 금지어 만 자당 검출(태그 `archive/v1-final` 의 원본 표), 답당 질문 수다.

채택 규칙은 숨긴 턴 세트에서 개선 턴이 악화 턴보다 많고 한쪽 부호 검정 p<0.05 이며 지적 없던 턴에서 악화가 늘지 않는 조건이다. 그 뒤 판독 후보 10~20쌍을 사용자가 판독하고, 판독이 판정과 다르면 판독을 따른다.

## 절차

1. 시험할지와 예상 비용을 사용자에게 먼저 제안한다. 2026-11-13 숨긴 세트 106턴의 판정 비용은 약 12달러였다.
2. 새 조건이 `v2.<n>` 이면 그 커밋 해시를 `%USERPROFILE%\.dc-eval\replay\V2_REV.<n>.txt` 에 적는다.
3. `bash scripts/eval_replay.sh evals/replay/turns-<이름>.txt <조건 A> <조건 B>` 로 세션 사본, 생성, 판정을 차례로 실행한다. 답은 `%USERPROFILE%\.dc-eval\replay\<이름>\`, 판정은 `%USERPROFILE%\.dc-eval\calib\<이름>\` 에 쌓인다.
4. `bash scripts/eval_replay_report.sh %USERPROFILE%\.dc-eval\calib\<이름> <조건 A> <조건 B>` 로 집계하고 판독 페이지(`reading-<A>-<B>.html`)를 만든다. 사용자가 「결과 복사」로 넘긴 JSON 을 파일로 두고 `--reading <파일>` 을 붙여 다시 집계한다.

## 실행 제약

- `claude -p` 는 평일 09:00~18:00 밖에서만 실행한다. 시작할 때와 턴마다 시작 직전에 확인하고, 실행 중 업무 시간에 들어가면 남은 턴을 취소한다. 사용자가 지금 하라고 하면 `--now` 를 붙인다(2026-11-17 사용자 지시).
- 생성·판정 모델은 `claude-opus-5-5` 다. 응답에 다른 모델이 있으면 답이나 판정을 쓰지 않고 멈춘다. 응답에 모델 기록(`modelUsage`)이 없으면 그 턴만 쓰지 않고 다음 실행에서 다시 만든다.
- 동시 실행은 `PAR`(기본 2)개, 여유 메모리가 `MEM_MIN_GB`(기본 2.5) 미만이면 다음 턴을 미룬다(2026-11-16 메모리 부족으로 예약 작업이 두 번 중단된 뒤 정했다).
- 같은 턴·같은 조건의 답과 같은 쌍의 판정은 다시 만들지 않는다. 표본은 턴 수로 늘린다(2026-10-18 사용자 지시).
- 생성 세션의 설정 폴더는 `EVAL_TMP`(기본 `D:/dc-eval-tmp`) 아래 임시 폴더라 실제 `~/.claude` 와 분리된다. 그 상위 경로에 CLAUDE.md 가 있으면 `eval_replay.sh` 가 멈춘다.
- 로그인 토큰은 실제 설정의 `.credentials.json` 에서 읽어 환경 변수로만 넘긴다. 남은 시간이 0.3시간 미만이면 갱신을 1분마다 다시 확인하고, 처음 기다리기 시작한 때부터 `TOKEN_WAIT_MIN`(기본 60)분이 지나면 남은 턴을 취소하고 멈춘다.
- 원본 세션 파일이 정리되어 없으면 `%USERPROFILE%\.dc-eval\replay\sessions-backup\` 의 사본을 읽는다. 사본은 `scripts/backup_sessions.py` 가 생성 전에 만든다.
