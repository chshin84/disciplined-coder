# 선행연구 검증자 Opus 묶음 판정 구성 재측정 결과

이 파일은 `python -I evals/prior-art-verifier/score.py report-v4` 가 만든다. 용어는 `docs/superpowers/plans/2026-10-22-prior-art-verifier-batch-judge.md` 「용어」를 따른다.

## 병합 조건

새 구성은 비용 조건을 충족했고, 항목 조건을 채우지 못했다.

- 비용 조건(새 구성의 실행마다 비용이 기준선의 어느 실행보다 낮다): 충족. 새 구성 $1.0468, $0.9614, 기준선 $3.3023, $2.9478.
- 항목 조건(기준선이 두 실행 모두 맞힌 항목은 새 구성도 두 실행 모두 맞힌다): 미충족. 비교한 항목·칸 45개, 기준선이 한 번 이상 틀려 빠진 항목·칸 13개(quo-t1, quo-t3, num-t3, dir-t2, hard-ctx-t1, hard-cnd-t1, hard-f200-t1, quo-t4, quo-t5, quo-t6, quo-t7, acc-t4, hard-f200-t2).
- 기준선 실행은 `cases-v2.json` 의 주장으로 만든 줄만 쓰고, 정답은 `cases-v3.json` 로 채점했다. 기준선 판정이 없는 항목: quo-t4, quo-t5, quo-t6, quo-t7, acc-t4, hard-f200-t2.
- 새 구성의 판정·재판정 입력은 ref 를 중립 번호(c1, c2 …)로 바꿨다. 기준선과 앞 재측정은 항목 id 를 ref 로 실행했다.
