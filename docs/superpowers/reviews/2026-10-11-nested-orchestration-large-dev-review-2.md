# nested-orchestration 설계 「2026-10-11 개정 — 묶는 단위」 리뷰 기록(2차)

대상은 `docs/superpowers/specs/2026-10-09-nested-orchestration-large-dev-design.md`의 「2026-10-11 개정 — 묶는 단위」 절이다. 1차 리뷰를 반영하고 사용자 결정 두 가지(DSM 근거를 표마다 나눔, 새 「공유 정의」 줄 대신 「결정 기록」)를 반영한 상태(브랜치 `shared-definition-grouping`, 커밋 e5a246d)를 보았다. 현재 세션은 경로가 `docs/superpowers/specs` 아래이므로 spec 으로 판정했다. 사용자가 다시 리뷰를 골랐다. 실행한 렌즈는 `lens-grounding`, `lens-consistency`, `lens-adversarial`, `lens-fit` 이고 원본은 같은 이름의 폴더에 줄여 옮겼다.

렌즈를 한 번씩만 실행했다.

현재 세션은 `lens-prior-art`를 제안하지 않았다. 1차와 같은 이유이고, 2차에서 새로 든 근거 문헌이 없다.

## 합친 지적 목록

| 지적 | 렌즈 원본 | 공동 |
|---|---|---|
| 떼어냄 행이 계약 표로 가는지 「결정 기록」으로 가는지 가르는 기준이 없고, '단위 관례'가 계약 표 단위 칸과 겹친다 | consistency 1 | 아니오 |
| 「결정 기록」에 용어 풀이를 적는 규칙이 스킬에 들어갈 위치와 확인 방법이 없다 | grounding 4 | 아니오 |
| 묶는 단계 규칙에 검증 의존 판정 지시가 없어 채택 기준 4번이 규칙 밖 출력을 측정한다 | consistency 2, adversarial 11 | 예 |
| NP-bond-agg 측정 입력의 워크스트림별 통합 확인 방법은 넷으로 합친 뒤의 문서라 정답이 샌다 | adversarial 6 | 아니오 |
| 함께 넣는 시험 병합의 브랜치·트레일러 절차가 없고, 직접 쌍인지 순환 전체인지 정하지 않았으며 실패 원인 쪽을 정할 수 없다 | consistency 3, adversarial 5 | 예 |
| 시작 의존과 검증 의존이 섞인 순환의 처리와 검사가 없다 | consistency 4 | 아니오 |
| 이미 병합된 대상을 고치면 그 대상에 검증 의존해 먼저 병합된 워크스트림의 확인이 무효가 되는데 재검사 범위가 좁다 | adversarial 4 | 아니오 |
| 통합 확인을 워크스트림마다 적는다고 정의했으나 스킬 「큰 명세」의 '공통 제약과 통합 확인 방법' 줄을 고칠 경로가 없다 | consistency 5 | 아니오 |
| '의존 순서'가 항목 전체와 시작 의존 두 뜻으로 쓰인다 | consistency 6 | 아니오 |
| 스킬 시험 병합은 이미 통합 확인을 실행하므로 '병합 전 검사에 넣는다'는 무엇을 더하는지 지목하지 않는다 | consistency 9 | 아니오 |
| '내부 의미에 기댄다'와 '접근 절차만 호출한다'를 가르는 판정 질문이 없다 | adversarial 1 | 아니오 |
| 소유 하위 프로젝트 없음이 판정 질문을 생략하는 우회 경로가 된다 | adversarial 2 | 아니오 |
| 떼어냄 행이 고정한 의미가 표에 남지 않아 승인 단계의 사용자 확인이 작동하지 않는다 | adversarial 3 | 아니오 |
| 기대 분할을 규칙 작성자가 적으면 자기 확증이 되고, 사용자에게 무엇을 보이는지 정하지 않았다 | adversarial 7 | 아니오 |
| 측정 폴더에 기대 분할과 승인 기록과 다시 만든 목록을 남기는 규칙이 없다 | consistency 8 | 아니오 |
| 채택 기준 1번 4/5 의 판정 오차(이항분포)를 밝히지 않았다 | adversarial 8 | 아니오 |
| 채택 기준 2번 '최다 분할'이 다수 과합침을 통과시키고, 3번은 불필요한 실패와 일관된 오답 통과를 낸다 | adversarial 9·10 | 아니오 |
| 근거 문단 수정을 확인하는 항목이 없고 validate 기대 출력이 없다 | consistency 7, fit 16 | 예 |
| 스킬과 앞 절은 DSM 을 구성 요소 사이 의존으로 풀이했으므로 '종류를 밝히지 않았다'는 진단이 원문과 다르다 | grounding 1 | 아니오 |
| Parnas 풀이가 접근 절차를 빼 인용문과 범위가 다르다 | grounding 2, fit notes | 예 |
| 재승인 줄 범위는 1360~1386행이다 | grounding 3 | 아니오 |
| 문체: 다섯 문장 단락, 문서·규칙을 주체로 씀, 주체 생략, '단위'·'공유'·'쓰는'·'합친 행' 용어 혼용, 개수 지칭, 서수로 대안 지칭, 한 문장 두 사건, 관형절 중간 삽입 | fit 1~15 | 아니오 |
| 절 제목 형식이 앞 개정 절과 다르다 | fit 17 | 아니오 |

## 커버리지 공백

4c 세션의 「계약 표」 절 원문은 `lens-grounding`만 선행연구 기록을 통해 간접으로 보았고, 칸 정의 원문은 어느 렌즈도 읽지 않았다. NP-bond-agg 기록 1363~1384행 큰 명세의 통합 확인이 워크스트림 단위로 적혀 있는지는 `lens-adversarial`이 열지 않았다고 밝혔다.
