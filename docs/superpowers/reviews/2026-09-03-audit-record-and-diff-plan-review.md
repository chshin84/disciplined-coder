# 감사 기록·대조 구현 계획 리뷰 (2026-09-03)

계획 `docs/superpowers/plans/2026-09-03-audit-record-and-diff.md`를 렌즈 셋(`lens-grounding`·`lens-consistency`·`lens-adversarial`)으로 한 번씩 리뷰했다. 지적은 마흔넷이고 합치니 스물여섯 주제다. 사용자 결정이 필요한 것(🔴)은 없다. 전부 고칠 것이다. 렌즈 원본은 같은 이름의 폴더에 있고, 선행연구 렌즈는 plan이라 제안하지 않았다.

## 합친 목록

둘 이상의 렌즈가 함께 잡은 것은 이름 뒤에 렌즈를 적었다.

- **요약문 봉인** (셋 모두) — `record()`가 요약문을 봉인 목록에 넣어 호출자가 뿌리와 물음을 붙일 수 없다. spec은 요약문을 봉인하지 않는다고 정했다.
- **검수 전 completed** (일관성·적대) — 검수 전에 `completed`를 참으로 놓고 봉인한다. 빈 파일 걸음은 검수 없이 자가 보고다.
- **일관성 원본 개수 규칙** (일관성·적대) — `pairs` 길이를 넘기는데 검수자는 `findings`를 센다.
- **요약문 경로 `..`와 개수** (근거·적대) — 폴더 밖 경로를 문자열 동등으로 견주고 마크다운에 개수 규칙을 건다.
- **표준 입력 충돌** (일관성) — `audit_targets.sh`가 파이프와 히어독으로 표준 입력을 두 번 쓴다. 이 PC에서 재현했다.
- **절 제목 루프 낱말 분리** (근거·일관성) — `audit_topics.sh` 테스트가 공백에서 쪼개진다.
- **`canonOf` 손 목록과 리터럴** (근거·일관성·적대) — 스킬·명령 이름을 손으로 적고 `'agent-principles.md'` 리터럴이 Task 6 단언을 위반한다.
- **뽑기 `file` 경로 꼴 미정** (일관성) — `canonOf` 비교가 경로 꼴에 기댄다.
- **`narrowed` 칸 부재** (일관성) — 문서는 렌즈가 돌려준다고 적는데 스키마에 없다.
- **`type` 칸 부재** (일관성) — 복제 발견의 `duplication`이 중복제거에서 사라진다.
- **첫 회차의 `diff.json` 부재** (일관성) — spec은 `no_prior_round`로 남기라 한다.
- **Task 6 스코프와 덩어리 1 낭비** (일관성·적대) — 전면 재작성이 Task 1·2를 버리고 `ROUND` 도출이 `args` 타입과 부딪힌다.
- **`run` 모양 드리프트** (일관성) — Task 2와 Task 6의 `run`이 다르고 spec 표에 없는 칸이 있다.
- **자가 검토의 커버리지 주장** (일관성) — 계약 테스트 매핑이 실제와 다르다.
- **성공 기준 둘 미검증** (일관성) — 호출 입력 상한과 08-30 어긋남 재검출.
- **Task 9·12 산출물 미기재** (일관성) — 회차 기록이 Files·Interfaces에 없다.
- **`meta`·phase 드리프트** (일관성) — 걸음을 더해도 `meta`가 낡고 대조가 반박검증 phase에 붙는다.
- **HANDOFF 필터 불일치** (일관성) — 테스트 기대 목록이 루트 `HANDOFF-`를 거르지 않는다.
- **인터프리터 이름** (적대) — 공유 헬퍼 `_json_valid.sh`가 있는데 `python`을 새로 적는다.
- **리뷰 기록 한 프롬프트** (적대) — 원본 아흔 개를 한 기록자가 옮겨 적어 실패 단위가 회차 전체다.
- **끊긴 폴더 통째 커밋** (적대) — 이력 검사가 삭제를 막아 되돌릴 수 없다.
- **레포를 건드리는 테스트** (근거·적대) — superseded 픽스처와 인자 없는 봉인이 레포 자신을 바꾼다.
- **걸음 표 누락 둘** (근거·적대) — 「진술을 뽑아 이름표로 모은다」·「회차를 대조한다」.
- **고유 발견 수 계산** (적대) — 쉼표로 이은 `lens`를 `===`로 견준다.
- **경로 단언의 따옴표** (근거·적대) — 홑따옴표 경로만 금지해 계약을 재지 못한다.
- **빈 봉인 목록** (적대) — 인자 없는 봉인 명령으로 뜻이 바뀐다.
- **`5,000` 단언의 자기 일치** (근거) — 단언 이름이 자기를 잡는다.
- **항진 단언 둘** (근거) — 훅이 없어도 참인 무출력 단언.
- **도출 `id` 번호 기준** (근거) — `judged.length`와 `deduped` 인덱스가 다르다.
- **기계 검사 가드 문장 소실** (근거) — 실패가 묻히는 형태 금지 문장이 빠졌다.
- **삽입 위치 문장 누락** (근거) — Task 10·11·12.
- **뜻 없는 단언** (근거) — `CLAUDE_PROJECT_DIR` 앞붙임.
