# 2026-09-21 원칙 분류 재배치 설계 — 렌즈 리뷰 기록

검토 대상은 `docs/superpowers/specs/2026-09-21-principles-taxonomy-design.md` 이다. 렌즈 넷을
대상 하나에 각각 하나씩 실행했다. 쓰기 도구가 없는 에이전트 종류로 실행해 읽기 전용을 구조로
강제했다.

렌즈를 한 번씩만 돌렸다.

선행연구 렌즈(`lens-prior-art`)는 붙이지 않았다. 발동 기준은 "아직 해본 적 없는 것을 해내려 하고
그것이 되는지 자체가 미지수인가"인데, 이 설계는 이미 있는 규칙을 재배치하고 이미 있는 검사의
제외를 해제하는 정리 작업이라 기준에 해당하지 않는다. 검토 대상이 `docs/superpowers/specs/`
아래에 있어 spec 으로 판정했다.

렌즈 원본은 같은 이름의 폴더에 둔다. 넷 가운데 `lens-fit-1.json` 하나만 전사에서 기계로 뽑혔고
나머지 셋은 추출에 실패했다. 실패를 숨기지 않고 적어 둔다. 그 셋의 전사는 이 세션의 작업 폴더
(`tasks/afa24af63047e356e.output`, `a3186ccb6daec01ce.output`, `aadbd0caee20c036f.output`)에 있으며
세션이 끝나면 사라진다. 아래 합친 목록이 그 내용을 대신한다.

| 절 제목 개명이 단언 열넷과 awk 블록 셋을 깨뜨린다 | consistency · adversarial | 사실이다. `test_scaffold.sh:549,563` 과 `428,510,631` 에서 확인했다 |
| `scripts/banned_words_waiver.txt` 가 설계에 없다 | grounding · adversarial | 사실이다. `until: 2026-10-20` 로 낱말 열여섯을 검사에서 뺀다 |
| 스코프 필터가 두 곳인데 설계는 하나만 고친다 | consistency · adversarial | 사실이다. `test_docs_drift.sh:805` 와 `868` 둘이다 |

## 단독 지적 가운데 확인된 것

수치가 넷 틀렸다. 검사 단언은 720개가 아니라 798개이고, 93은 대조 문자열이 아니라 화면에 찍히는
설명 라벨의 수이며 실제 대조 문자열은 33개다. 한국어 조항은 스물다섯이 아니라 스물넷이다. 낱말
45종은 백틱을 걷지 않고 센 값이고 완료 확인에 쓸 `banned_report` 의 셈법으로는 44종이다.

같은 문서 안에서 `정본` 이 든 파일 수가 19와 22로 두 번 적혔다.

Karpathy 매핑 표의 원문 인용 열 줄 가운데 여섯 줄이 실제 문장과 글자가 다르다.

대체어 `원본` 이 이 저장소에서 이미 외부 금지어 저장소를 가리킨다. `korean-banned-words.md:5` 와
`test_docs_drift.sh:791` 에서 확인했다. 교체하면 한 낱말이 두 대상을 가리킨다.

전역 사본으로 복사되는 파일은 `scripts/_scaffold_common.sh:5` 에서 둘로 고정되어 있다. 신설하려는
참고서는 다른 프로젝트에 도달하지 않는다.

`banned_scan` 은 백틱과 코드 블록을 걷지 않는다. `banned_report` 만 걷는다. 따라서 검사 경로에서는
백틱으로 감싸 인용을 살리는 방법이 통하지 않는다.

`test_hooks.sh:328` 이 이 저장소 문서에 훅이 아무것도 내지 않아야 한다고 단언한다. 제외를 해제하면
이 단언을 뒤집어야 한다.

코딩 절의 참고서가 표에 없다. `DERIVE-FIRST` 가 `SSOT` 의 둘째 문장과 같은 요구다. `YAGNI` 만
뜻이 풀리지 않는 영어 약어다.

형식 지적이 열 건이다. 소제목 넷이 명사구가 아니고, 소제목 여섯이 결론 문장 없이 표로 넘어가며,
표 넷에서 같은 열의 말끝이 섞이고, 연결어미 뒤 쉼표가 여덟 곳이며, 「스위치」가 지어낸 비유다.

## 상충

`numbered steps` 의 처분이 두 표에서 다르다. 「중복 소유와 상충」 표는 예외 명시만 말하고 「Karpathy
해체 매핑」 표는 `CHECKABLE` 로 흡수한다고 말한다. 결과가 서로 다르다.

`FOCUSED` 를 좁힌다는 처분이 매핑 표와 분해 표 어디에도 대응 행이 없다.

## 커버리지 공백

`lens-fit` 이 `UNPACK` 의 적용 범위를 판정 보류했다. `agent-principles.md:68-70` 은 산출물에 모두
적용한다고 읽히는데 `domain-korean.md:164` 는 문서를 명시적으로 뺀다. 계약 둘이 서로 다르다.

`lens-adversarial` 은 읽기 전용이라 검사 스크립트를 실행하지 못해 단언 수를 눈으로 셌다.

설계가 든 상충 넷 가운데 셋(`FOCUSED`·`ASK-CONTEXT`·`ASYNC-FIRST`)의 근거가 약하다는 지적이
`lens-grounding` 에서 나왔고, 조건절이 이미 서로 겹치지 않는다는 근거를 확인했다.
