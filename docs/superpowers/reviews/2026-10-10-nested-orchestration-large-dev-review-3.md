# nested-orchestration 큰 개발 분할 — 2026-10-10 개정 3차 리뷰

대상은 2차 리뷰(`2026-10-10-nested-orchestration-large-dev-review-2.md`) 뒤 「묶는 단위」를 순환만 합치는 규칙으로 바꾸고 하위 프로젝트 목록을 사용자 승인으로 고정한 `docs/superpowers/specs/2026-10-09-nested-orchestration-large-dev-design.md` 「2026-10-10 개정」 절이다. 함께 바뀐 `skills/nested-orchestration/SKILL.md`, `agent-principles.md` 「병렬 오케스트레이션」, `docs/domain-discipline.md` `SUB-ORCHESTRATE` 절을 대상으로 넘겼다. 사용자가 다시 리뷰를 골랐다.

렌즈를 한 번씩만 실행했다. 실행한 렌즈는 `lens-grounding`, `lens-consistency`, `lens-adversarial`, `lens-fit` 이고 원본은 같은 이름의 폴더에 있다. `lens-fit` 원본은 필드를 줄여 옮겼다.

선행연구 렌즈는 제안하지 않았다. 같은 날 분해 기준의 선행연구 대조(`2026-10-10-decomposition-criteria-prior-art.md`)를 이미 실행했기 때문이다.

## 거른 지적

거른 지적은 없다. 현재 세션이 `lens-grounding` 의 수치 지적을 재현성 측정 채점 출력과 대조했고, 의존 판정이 달랐던 실행은 해당 요청마다 1회였다.

## 합친 지적

괄호는 같은 지적을 잡은 렌즈다.

- **측정 수치의 과장** (grounding) — 순환만 합치는 조건의 의존 판정 불일치는 요청마다 1회인데 '1~2회'로 적었다. 이전 규칙은 최빈 분할이 4/5·2/5 였는데 '실행마다 달랐다'로 적었다. 열거 단계는 이름 옮기기 조건이 두 요청에서 재현되었는데 SKILL 은 '실행마다 달랐다'로 일반화했다.
- **순환 탐지의 한계 누락** (grounding, adversarial) — SKILL 은 재현성만 적고, 그 분할이 '무조건 분리' 기준선과 거의 같았으며 심은 순환을 어느 실행도 잡지 못했다는 사실은 spec 에만 있다.
- **라우팅 빈칸** (adversarial, consistency, fit) — 넷째 불릿을 좁힌 뒤 첫 층이 둘 이상이지만 태스크 다섯 미만 워크스트림이 있는 큰 개발을 어느 불릿도 받지 않는다. '서로 독립된 큰 작업이 하나뿐'은 '서로'와 맞지 않는다.
- **첫 층과 동시 진행 조건** (adversarial, consistency, fit) — 「흐름」의 동시 진행 조건에 경로 겹침이 남아 첫 층 정의와 다르다.
- **다른 저장소의 실행 위치** (adversarial) — 현재 세션의 체크아웃이 없는 다른 저장소에서 워크트리 생성·범위 대조·시험 병합을 어디서 하는지 적혀 있지 않다.
- **원칙 머리 문장의 범위와 조항 문장** (consistency, fit) — 머리 문장의 '하위 프로젝트로 분해할 때'에 분해하지 않은 큰 개발의 설계 승인 시점이 들지 않는다. 조항 문장은 '전에'가 두 번 이어져 두 가지로 읽힌다.
- **스킬의 '나누다'** (consistency, fit) — 원칙은 분해와 맡김을 구분했으나 스킬 description·절 이름·본문은 '나누다'를 두 뜻으로 쓴다.
- **'층'의 두 뜻** (fit) — 의존 순서의 '첫 층'이 3층 오케스트레이션의 '층'과 같은 낱말이다.
- **재시험 기술의 불일치** (consistency, fit) — domain-discipline 은 고친 뒤 네 세션이 모두 동작했다고 적으나, spec 에 따르면 고친 뒤 다시 실행한 세션은 서로 독립된 큰 작업 둘뿐이다.
- **설계 승인 뒤 보강 항목** (consistency) — spec 「판단 시점」의 보강 목록에 의존 순서가 없다.
- **분해하지 않은 큰 개발의 목록 출처** (fit) — 설계 승인 뒤 판단하는 큰 개발에서 「묶는 단위」의 입력 목록을 누가 만드는지 적혀 있지 않다.
- **서로 독립된 큰 작업의 승인 근거** (fit) — 승인에 보일 근거가 「나누는 기준」의 근거 항목과 같은지 정해져 있지 않다.
- **잠금 파일 예외** (fit) — spec 「묶는 단위」의 '같은 파일은 공용 파일'이 의존성 목록·잠금 파일의 단일 워크스트림 소유 규칙과 다르다.
- **선행연구 기록 둘의 관계** (adversarial) — 개정 절이 선행연구 기록 둘을 관계 설명 없이 인용한다.
- **문체** (fit) — 네 문장을 넘는 단락, 개수 예고, '큰 작업'의 순환 정의, DSM·axiomatic design·ARI 의 풀이 누락.

## 커버리지 공백

렌즈들이 재현성 측정 원본을 연 것은 `lens-grounding` 하나다. 원칙 문구 재시험의 원본은 대화 안에만 있어 어느 렌즈도 열지 못했다.
