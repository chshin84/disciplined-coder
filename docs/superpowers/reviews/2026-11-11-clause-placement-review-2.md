# 조항 배치 재설계 spec 2차 리뷰

대상은 `docs/superpowers/specs/2026-11-11-clause-placement-design.md` 의 2차 차수다. 1차 리뷰 반영과 행위 모델 변경(사용자 지적, 2026-11-11)으로 바뀐 절을 다시 보았다. 렌즈 원본은 같은 이름의 폴더에 있다.

렌즈를 한 번씩만 실행했다. 실행한 렌즈는 lens-consistency(spec), lens-adversarial(design), lens-grounding(spec), lens-fit(auto)이다. 선행연구 스킬은 같은 날 별도로 실행했다(`2026-11-11-decision-points-prior-art.md`).

## 거른 지적

lens-grounding 은 "내비두고"를 병합 보류로 읽은 해석에 근거가 없다고 지적했다. 그 뒤 사용자는 2026-11-11 에 결정 전체를 위임했으므로("다 진행해줘 ... 판단을 해봐") 리마인더를 시험 대상에 넣는 판단도 위임 범위에 든다. 그래서 해석 근거를 위임 발언으로 바꿔 적고 지적은 걸렀다.

lens-fit 은 표 셀의 할 일도 '~하라'로 쓰라고 했다. 원칙 `FULL-SENTENCE` 는 표 셀에 명사구와 명사형 종결을 허용하므로, 표 셀은 명사형 종결로 맞추고 '~하라'를 강제하지 않는다.

## 처분

🔴 는 없다. 사용자가 2026-11-11 에 결정을 위임하고 질문하지 말라고 했기 때문이다. 1차 리뷰의 🔴 였던 2026-10-18 지시 예외도 위임 범위에서 Claude 가 정하고, 그 판단을 spec 「기준선」과 결정 기록에 적는다. 나머지 지적은 모두 고친다.

| 지적 | 렌즈 | 처분 |
|---|---|---|
| 5번에 현행 위반 하한이 없고, 매 턴·기계 검사 조건이 경계에서 겹친다 | adversarial, consistency | 현행 위반이 지적 턴의 절반 이상일 때만 판정하고, 매 턴 조건을 먼저 본다 |
| 사용자 판독이 판정자와 다를 때의 규칙이 없다 | adversarial | 판독 표본에서 사용자 판정을 따르고, 판정이 뒤집힌 후보는 다시 판정한다 |
| 조항 배정이 단일 판정자이고 복수 배정 턴이 겹쳐 셈된다 | adversarial | 판독 표본에 배정 확인을 넣고 복수 배정 턴을 따로 표시한다 |
| 5번은 위반 수만 보고 '필요 정보 누락'의 정의가 없다 | adversarial | 누락의 정의를 적고 10번 지표로만 쓴다 |
| 4건 미만 조항의 재현은 쓰이지 않는다 | adversarial | 4번에서 바로 상주로 확정한다 |
| 상위 5개 비교는 217자 상한과 맞지 않는다 | adversarial | 뺀다 |
| 대조 조건의 '같으면' 기준과 비교 단위가 없고 받는 단계가 없다 | adversarial, consistency | 같은 턴 묶음, 1건 이내를 같음으로 정하고 6번이 받는다 |
| reply-reminder 대체 병합의 근거가 약하다 | adversarial | 5번에서 현재 리마인더가 매 턴 기준을 넘은 때로 한정한다 |
| 9번이 상주 조항 문구도 바꾸므로 '나빠지지 않는다'가 틀리다 | adversarial | 상주 조항은 합친 조항 외에는 문구를 바꾸지 않는다 |
| 경로 표기가 문서마다 다르다 | adversarial | 절대 경로로 맞춘다 |
| 01 기록에 「실행 순서」·행동 열이 없고 '쓰기 셋'이 spec 에 없다 | consistency | 완료 기준을 결정점과 비용 항목·제약으로 고치고, '쓰기 공통'을 결정점 표에 정의하고, 01 기록을 고친다 |
| 하한 단위(조항·결정점)가 섞이고, 현행·이전 문구 칸을 어느 쪽으로 세는지 없다 | consistency, grounding | 조항 단위·합계로 정한다 |
| 열림 시험에 실패한 스킬 후보, 지적이 있는 삭제 후보, 배치가 다른 합치기 후보의 경로가 없다 | consistency | 5번·7번으로 보내고, 배치가 다르면 합치지 않는다 |
| 가이드 후보 작성 단계, 스킬 description 기준값, 지속성 검사의 단계가 없다 | consistency | 4번에 가이드 후보 작성을, 완료 기준에 합계 기준을, 9번에 지속성 검사를 넣는다 |
| Fable 답의 충돌 귀속, 수집 시작일, 클린룸 정의, 턴 단위 리마인더 근거, 위임 발언 누락, 대조 문구 귀속, 2026-10-18 비교 조건, 비가역 문장 | grounding | 출처대로 고친다 |
| 할 일의 '~한다', 무생물 주어, 관형절, 용어 섞임, '오늘', 개수, 불릿, 표 말끝, 대구, 맥락 누락 | fit | 고친다 |

## 다시 리뷰 판단

남은 지적 중 설계를 틀리게 만드는 지적은 없다. 반영은 판정 규칙의 경계와 단계 사이 경로를 메우는 수정이고, 결정점 정책 모델과 배치 구조는 그대로다. 그래서 3차 리뷰는 하지 않고 그 판단을 spec 본문에 적는다.
