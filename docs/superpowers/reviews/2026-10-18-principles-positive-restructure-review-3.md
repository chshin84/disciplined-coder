# 에이전트원칙 개편 spec 3차 리뷰 — 2026-10-18

대상은 `docs/superpowers/specs/2026-10-18-principles-positive-restructure-design.md` 의 시험 방법 개정(조항별 클린룸, 질문 추가, 반복 없음, 금지어 목록 단위)이다. 사용자가 바뀐 부분만 다시 리뷰하기로 정했으므로, 메인 세션은 2차 리뷰와 같이 consistency 렌즈와 adversarial 렌즈만 실행했다. 렌즈를 한 번씩만 실행했다. 이번 개정은 이미 정한 설계의 시험 절차를 바꾸는 일이라 선행연구 렌즈는 제안하지 않았다. 렌즈별 원본은 같은 이름의 폴더에 있다.

## 합친 지적 목록

| 지적 | 잡은 렌즈 |
|---|---|
| 기존 조항에서 나눈 신설 조항(`CONFIRM-IRREVERSIBLE`, `OTHER-SESSIONS`, `REVIEW-DELIVERABLE`)을 문구 변경으로 볼지 새 조항으로 볼지 없다. 하나씩 따로 시험하면 현행과 변경안의 범위가 달라 비교가 성립하지 않고, 한쪽만 채택되면 내용이 겹치거나 빠진다 | consistency, adversarial |
| 나눔 신설 불변 조건이 새 조항 규칙에 걸리면 조항 없음 조건이 모두 지킬 때 '넣지 않음'이 되어 사용자가 정한 불변 범위가 빠질 수 있다 | adversarial |
| 새 조항의 동률(조항 없음 위반이 0 보다 크고 변경안이 그 이상)과 금지어의 동률에 판정 규칙이 없다. 금지어 단계의 되돌림 조건이 두 곳에서 다르다 | consistency, adversarial |
| 전체 비교의 주 기준이 문안 선택에 쓴 질문을 포함한 합계라, 보류용을 따로 두는 이유와 부딪친다 | consistency, adversarial |
| 새 질문을 '그 조항의 문안'에서 만들면 변경안에만 있는 상황을 겨눠 시험이 변경안에 맞춰진다 | adversarial |
| 0 대 0 동률이 흔해, 확장 뒤 '이하'로 채택되는 조항은 측정 차이가 없었다는 뜻이다 | adversarial |
| 실행 스크립트는 반복 3회이고 판정 읽기 실패를 위반 아님으로 센다 | adversarial |
| 문구 변경 판정은 조항 없음 결과를 쓰지 않는데 모든 조항에 실행한다. 여러 조항을 태그한 과제는 판정 기준이 하나라 다른 조항의 위반이 섞인다 | adversarial |
| 금지어 시험을 훅·스크립트 전환 뒤에 두어 실패하면 여러 파일을 되돌려야 한다 | adversarial |
| 전체 비교가 실패할 때의 다음 행동이 없다 | adversarial |
| 예상 실행 건수와 비용을 미리 확인받는 문장이 없다 | adversarial |
| CLAUDE.md 의 '과제 3개+2개' 문장을 그대로 두고 덧붙이면 규칙이 둘이 된다 | adversarial |
| '모든 단계는 이 파일과 비교', '단계마다 판정 10건' 이 개정 전 문장으로 남았다 | consistency |
| `EDIT-PRIORITY` 의 `current.md` 옮김 규칙에 대화 답 제외 문장이 들지 않는다 | consistency |
| 조항 파일이 '이유'를 소유한다고 적었으나 이유 칸이 놓일 곳이 없다 | consistency |
| '합계 3 미만이면 하나 더'와 짝 구성이 '사용자가 정한 것' 아래에 있다 | consistency |
| 과제·질문, 조항 없음·조항 없는 조건 등 이름이 섞이고 '질문'·'전체 비교'가 정의되지 않았다 | consistency |
| 영향 파일 목록에 Python 헬퍼와 검사 스크립트가 없다 | consistency |

## 커버리지 공백

바뀐 부분만 대상으로 삼았으므로 grounding·fit 렌즈를 실행하지 않았다. 렌즈 노트의 '이건 앞으로도'가 질문 추가까지 가리키는지는 지시 원문으로 정해지지 않는다.
