# 2026-10-18 선행연구 대조 — 선행연구 에이전트 구상

## 실행 판정

- **발동** — 사용자가 "선행연구렌즈로 뒤져봐줘"라고 직접 요청했다. 이 요청을 승인으로 보았다(`dispatching-lenses` 「렌즈 그룹」의 직접 요청 규칙).
- **규모** — 메인 세션이 하위 질문 4개와 이중화 1개, 합계 5개를 제안했고 사용자가 승인했다. 같은 대화에서 사용자는 상한을 통상 2, 최대 20으로 바꾸기로 정했으며, 이 차수는 그 새 상한 안에서 실행했다. 스킬 파일의 상한 문구(최대한 6)는 이 차수 시점에 고치기 전이었다.
- **대상** — spec이 아닌 설계 구상이다. 렌즈에 넘긴 원문은 「선행연구 에이전트」 구상 한 단락이다(렌즈 원본의 프롬프트와 같다). 이 구상은 뒤에 `docs/superpowers/specs/2026-10-18-prior-art-agent-design.md`가 되었다.
- **실행 방식** — 렌즈를 한 번씩만 실행했다. 렌즈마다 general-purpose 서브에이전트 하나를 썼다. 읽기 전용은 프롬프트로만 지시했다.

## 이중화 대조

순번 1과 2는 서로의 결과를 모른 채 같은 결론을 냈다. 선행연구 대조(기시감·결말·전이·붐빔과 네 축 대조)를 목적으로 하는 에이전트는 찾지 못했고, 일반 리서치 골격은 붐빈다는 결론이다. 두 렌즈가 찾은 후보는 겹치지 않았다. 순번 1은 내장 `/deep-research`와 설치된 deep-research 스킬과 마켓플레이스 목록을, 순번 2는 insane-research·hyperresearch·academic-research-skills·cookbook 프롬프트를 찾았다.

## 결론에 영향을 주는 not_found와 disclosures

- 같은 모델 에이전트 둘을 서로 다른 검색 경로에 배치했을 때의 오류 상관을 측정한 연구는 찾지 못했다(순번 5). 이중화 효과는 측정해야 정해진다.
- 내장 `/deep-research`의 스크립트 내부(각도 수, 투표 기준)는 공식 문서에 없어 확인하지 못했다(순번 1).
- WebFetch가 요약 모델을 거치므로, 렌즈가 옮긴 수치 일부는 원문 문장 그대로가 아닐 수 있다고 렌즈 3·4·5가 밝혔다.
- 선행 저장소의 실측 기록(CHANGELOG, 자체 벤치마크)은 저자의 자기 보고다(순번 2).
