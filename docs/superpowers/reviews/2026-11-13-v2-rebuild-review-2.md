# v2 재건축 0~3단계 plan 리뷰 (2026-11-13, 두 번째 차수)

대상은 `docs/superpowers/plans/2026-11-13-v2-rebuild-stage0-3.md` 다. 경로가 `plans` 아래라 plan 으로 판정했고 선행연구 스킬은 제안하지 않았다(plan). 렌즈는 `lens-grounding`(spec), `lens-consistency`(plan, 짝 spec 포함), `lens-adversarial`(design), `lens-fit`(auto) 네 개를 한 번씩만 실행했다. 서브에이전트 출력 파일이 비어 원본 JSON 은 메인 세션이 받은 보고에서 줄여 옮겼다.

## 함께 지적된 항목

- **superseded 검사 교체:** 경로 고정 검사를 지우면 이미 표시가 달린 옛 spec 두 개를 지키는 검사가 없어진다(grounding·consistency).
- **V2_REV 덮어쓰기:** 시험한 v2 와 채택하는 v2 가 달라질 수 있고 결과 파일에 생성 리비전이 없다(adversarial·consistency).
- **두 번째 숨긴 세트:** 분류·선정 도구가 60·60, 120턴으로 고정이라 확대와 이어받기가 안 된다(adversarial·consistency).
- **비용 계산식:** 분류 호출과 재시험 확대가 빠졌고 확인 지점이 하나다(adversarial·consistency). 단가 근거도 짧은 판정 틀의 값이다(grounding).
- **도구 인터페이스:** 행별 금지어 출력, 사용자 판독 재집계 입력, 금지어 목록 파일 생성 단계가 없다(fit·consistency).

## 단독 지적

- grounding: spec 과 다른 상시 보기 분량 해석, 결함 주입 방법이 spec 표와 다름, out1·out2 의 #번호 기준 미확인.
- consistency: 핵심 계약 재사용을 「spec 과 다른 점」에 안 적음, 금지어 비교가 통과 조건에 없음, 판독 과반 입력 형식, 임시 폴더 접두어.
- adversarial: 미달 경로에 기록·브랜치 처분 없음, 결함 주입 판정이 기대 검사 이름을 대조하지 않음, 판정도 구독 한도를 쓰는데 시간 제약은 생성에만 둠, 판정 인용문이 공개 저장소에 들어갈 위험, 중단 시 잘린 결과 파일, 숨긴 세트 후보가 요구 분석 입력과 겹침, 조건부 설정 값 과설계.
- fit: 도구 네 개를 확인 없이 한 단계에서 만듦, 산문 테스트 단계, 임계값 없는 분기, Files 블록 없는 태스크, spec 에 없는 업무 시간 값, 표 머리 '할 일', 개수 참조.

## 걸러 낸 지적

- fit 「spec 에 없는 업무 시간 경계」: spec 위험 표가 "생성은 업무 시간 밖에 몰아 실행한다"를 정했고 plan 은 그 경계값을 정한 것이다. 출처 표시만 남기고 반영하지 않는다.
- adversarial 「숨긴 세트 후보가 msgs.jsonl 안」: msgs.jsonl 은 모든 세션의 사용자 메시지 전체라 그 밖의 메시지가 없다. 대신 인용 제외를 엄격히 하는 쪽(#번호 기준 확인)으로 처리한다.
