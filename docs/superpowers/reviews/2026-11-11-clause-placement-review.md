# 조항 배치 재설계 spec 리뷰

대상은 `docs/superpowers/specs/2026-11-11-clause-placement-design.md` 의 첫 차수다. 경로가 `specs/` 아래라 spec 으로 구분했다. 렌즈 원본은 같은 이름의 폴더에 있다.

렌즈를 한 번씩만 실행했다. 실행한 렌즈는 lens-grounding(spec), lens-consistency(spec), lens-adversarial(design), lens-fit(auto)이다.

선행연구 스킬은 제안하지 않았다. 이 spec 의 방법(실제 세션 재현, 매 턴 리마인더)은 같은 날 선행연구(`2026-11-11-comm-violation-methods-prior-art.md`)와 재현 시험으로 이미 근거를 모았다. 그래서 되는지 자체가 미지수인 일로 보지 않았다.

## 거른 지적

lens-grounding 은 사용자 발언 인용 "너가 주체니깐 나한테 뭘할지 역으로 제안해주는게 좋아"가 출처에 없다고 지적했다. 이 문장은 2026-11-11 이 세션에서 사용자가 실제로 한 발언이다. 렌즈에 이 대화 원문을 넘기지 않아 생긴 지적이므로 걸렀다. 본문에는 발언 날짜를 적는다.

lens-fit 은 「작업 지시서」 형식 지적(할 일을 '~한다'로 씀)의 기각 가능성을 적었다. 원칙 `INSTRUCTION-FORM` 이 spec 에 적용되므로 거르지 않고 반영한다.

## 병합한 지적과 처분

🔴 는 하나다. 나머지는 고친다.

| 지적 | 렌즈 | 처분 |
|---|---|---|
| 9번 조합 시험은 2026-10-18 사용자 지시(묶음 비교 금지, 같은 조건 재실행 금지) 두 가지와 부딪친다. spec 은 앞의 금지만 예외로 묻는다 | consistency, adversarial | 🔴 사용자 지시의 예외라서 사용자 가치판단이 필요하다. 두 금지를 함께 묻도록 고친다 |
| 재현 스크립트와 중간 결과가 세션 전용 scratchpad 에 있다 | adversarial | 저장소 밖의 고정 폴더로 옮기도록 고친다 |
| 5번에 조항별 표본 하한과 동률 처리가 없다. 판정 19%가 뒤집히는 조건에서 배치가 잡음으로 바뀐다 | adversarial | 하한과 판정 규칙, 판정이 서지 않을 때 상주에 두는 기본값을 넣는다 |
| 지적이 있는 조항이 줄지 않으면 삭제로 갈 수 있고, 삭제 전에 사용자에게 묻는 단계가 없다 | adversarial, consistency | 삭제는 사용자 확인을 거치고, 판정이 서지 않으면 상주에 둔다 |
| 4번의 무작위 5개 시험은 재현할 턴이 없어 실행할 수 없다 | adversarial, consistency | 빼고, 지적 0회 조항은 현행 위치를 유지한다고 적는다. 위험은 「남은 위험」에 둔다 |
| 2번 기간 확장에 상한이 없고 원칙 버전이 섞인다 | adversarial | 기간을 고정하고 턴마다 원칙 커밋을 기록한다 |
| 6번은 지적 횟수로 정렬해 수집 편향이 결과를 정한다 | adversarial | 5번에서 측정한 감소폭으로 정렬한다 |
| 매 턴 3개 제한의 근거(Replit)는 주입 횟수와 도구 실행을 측정했다 | adversarial | 근거의 성격을 적고 칸 수를 6번에서 시험 변수로 둔다 |
| 7번 주입 간격 시험은 비용 대비 과하고 재현으로 측정할 수 없다 | adversarial, consistency | 7번을 뺀다 |
| 9번의 '현행 이하'와 완료 기준의 '현행보다 적고'가 다르다 | adversarial, consistency | 완료 기준에 맞춘다 |
| 실행 수 추정과 비용 상한, 사용자 제안 절차가 없다 | adversarial | 5번과 9번 앞에 추정과 제안 단계를 넣는다 |
| 사용자 판독이 후보마다 5쌍이라 부담이 크고 표본 규칙이 없다 | adversarial | 단계마다 10쌍을 묶어 메모리 기준대로 고른다 |
| 행위 모델 지표 대부분을 재현으로 측정할 수 없다 | adversarial | 지표를 재현에서 판정할 수 있는 질문으로 바꾼다 |
| 1번에서 합치거나 나눈 조항은 5번의 기준 조건이 없다 | adversarial | 1번은 표시만 하고, 문구 변경은 배치를 정한 뒤 구성 단계에서 한다 |
| reply-reminder 처분이 9번 통과에만 묶였다 | adversarial | 9번이 실패하거나 예외가 거부되면 리마인더만 병합하는 안을 사용자에게 제안한다고 적는다 |
| 판독 0쌍은 감독자 문구 전 조건의 결과다 | grounding, consistency | 귀속을 고친다 |
| 표기 형식의 셋째 칸 이름이 원문과 다르다 | grounding | 원문대로 고친다 |
| 측정한 문단은 「Communicating clearly」 문단이다 | grounding | 측정한 문단과 low-context reader 문단을 나눠 적는다 |
| 조항 충돌 예시의 출처가 없다 | grounding | 출처(Fable 5.2 답 세 개, 저장소 밖)를 적는다 |
| '내비두고' 지시와 다르게 처리한 판단 근거가 없다 | grounding | 지시를 병합 보류로 읽은 해석과 근거를 적는다 |
| 54ee432 를 '되돌렸다'로 적었고 2026-10-25 사용자 결정(열림 시험 선행)을 빠뜨렸다 | grounding | 고친다 |
| 21건 혼입이 어느 시험인지 구분되지 않는다 | grounding | 문구 변형 시험으로 적는다 |
| 소유 문장 부작용 중 출력 토큰 1.5배를 뺐다 | grounding | 넣고 답 길이를 지표로 둔다 |
| 스킬 후보와 매 턴 후보가 겹칠 수 있다 | consistency | 스킬 후보는 5번에서 뺀다 |
| 1번 삭제 후보의 확정 단계가 없고 삭제 정의에 사유가 빠졌다 | consistency | 고친다 |
| 5번에 상주로 가는 출구가 없다 | consistency | 판정이 서지 않으면 상주로 둔다 |
| 6번에서 밀려난 후보의 배치가 정의와 맞지 않는다 | consistency | 상주 정의에 '매 턴 칸에서 밀려난 조항'을 넣는다 |
| 현행 리마인더 줄과 가이드 후보의 시험 입력이 없다 | consistency | 줄마다 대응 조항의 지적 턴을 입력으로 쓴다 |
| 원칙 문안 작성, 스킬 이동, 훅 수정 단계와 배치표 위치가 없다 | consistency | 구성 단계와 결정 기록 경로를 넣는다 |
| 원칙 글자 수를 측정하는 단계가 없다 | consistency | 9번 지표에 넣는다 |
| 브랜치 처분이 세 범주로 확정되지 않았다 | consistency | 확정한다 |
| 같은 수단을 세 이름으로 부른다 | consistency, fit | 「콘솔 답변 교정」 하나로 맞춘다 |
| 턴 단위 리마인더 행의 '전달 외 전체' 배정 | consistency | 전달로 고친다 |
| 가이드 반영이 완료 기준과 연결되지 않는다 | consistency | 완료 기준에 넣는다 |
| 할 일을 '~하라'로 쓰지 않았고 부정문을 썼다 | fit | 고친다 |
| 맥락을 이름만 대고 풀지 않았다, '오늘' | fit | 고친다 |
| 무생물 주어, 관형절, 수식어 중첩, 용어 섞임, 개수, 표 말끝, 불릿 논증, '그러므로', '당긴다' | fit | 고친다 |

## 다시 리뷰 판단

반영으로 판정 순서와 완료 기준이 바뀐다. 그래서 고친 spec 의 판정 순서 절만 다시 리뷰할지는 반영 뒤 메인 세션이 `NO-RAW-OUTPUT` 대로 정하고 그 판단을 spec 본문에 적는다.
