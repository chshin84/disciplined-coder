# v2 재건축 설계 리뷰 (2026-11-13)

대상은 `docs/superpowers/specs/2026-11-13-v2-rebuild-design.md` 다. 경로가 `specs` 아래이므로 spec 으로 판정했다. 렌즈는 `lens-grounding`(spec), `lens-consistency`(spec), `lens-adversarial`(design), `lens-fit`(auto) 네 개를 한 번씩만 실행했다. 원본은 같은 이름 폴더에 있다. 서브에이전트 출력 파일이 비어 있어 원본 JSON 세 개(grounding·consistency·adversarial)는 메인 세션이 받은 보고에서 옮겼고 일부 문장과 경로를 줄였다.

선행연구 스킬은 제안하지 않았다. 이 spec 은 있던 플러그인을 다시 짜는 정리 작업이고, 되는지 자체가 미지수인 새 기능이 아니기 때문이다.

## 함께 지적된 항목

- **superseded 표시 시점:** 1단계의 새 superseded 검사가 현행에서 FAIL=0 이어야 하는데 대상 6개 문서의 표시는 7단계에 붙인다(grounding·consistency·adversarial).
- **실패 시 대체 경로:** 상시 지시를 v1 으로 두고 4~7단계를 진행하면 v1 원칙이 지운 스킬·훅을 가리키고, 완료 기준과도 맞지 않는다(consistency 둘·adversarial).
- **리마인더 셋째 줄과 역할 조항:** 먼저 물을 결정의 범위가 다르다(consistency·adversarial).
- **판독 페이지 형식 소유:** CLAUDE.md 「판독 페이지」와 side-by-side 스킬 두 곳이다(세 렌즈).

## 단독 지적

- grounding: 사용자 원문 반복 횟수(세 세션 → 두 세션), REVERSIBLE 위임 문장이 push 를 열어 둠, 역할 조항 측정 인용이 채택 문장과 다름, FOCUSED 소유처 없음, 결정 기록 정정에서 R01~R13 누락, 10-25 지시 범위 확대, 50달러 상시 기준, 선행연구 제안 삭제를 사용자 지시로 단정, 테스트 동시 3개 근거 없음, 숨긴 세트 120턴 근거 없음.
- consistency: 메모리 정리 시점 두 곳, 사용자 확인 1 을 받는 단계 없음, 보존한 v1 근거 절이 지운 경로를 가리킴, 보조 계약 작성 단계 없음, 완료 기준이 판정하지 않는 산출물, 3단계 실행 도구 미정, 턴 수 표기 차이(29·30, 110·113).
- adversarial: push 와 자동 갱신으로 모든 PC 에 퍼지는 배포 단계 없음, 숨긴 세트 오염(out4·synthesis 인용, 판정 기준 순환), 재시험이 같은 숨긴 세트를 씀, 개선 턴 경계값 미정, 대화 기록 모방 오차, 비용 합계에서 재시험과 구독 한도 누락, RUN-IT 경로 안내 문장, 측정 없는 상시 문장, 설치·갱신 코드 재작성 위험, 제외어 없는 상시 보기의 부작용.
- fit: 역할 조항과 근거 조항이 여러 관심사를 섞음, 목표 문장과 표 머리의 '일', '결재를 올리듯' 비유.

## 걸러 낸 지적

- adversarial 「측정 없는 상시 문장」 중 RESOURCES 의 임시 자원 정리 문장: 사용자 원문 지시(`가비지 콜렉션 유의해 달라`)가 있어 측정 없이 둘 근거가 있다. 워커 결과 검증 문장도 2026-11-13 사용자가 승인한 역할 구조의 일부다. 두 문장은 반영하지 않는다.
- consistency 「사용자 확인 1 을 받는 단계 없음」: 사용자는 2026-11-13 에 현행과 새 원칙을 실제 대화로 비교하는 계획을 "전부 진행하자"로 승인했다. 확인 단계를 추가하지 않고 spec 에 그 승인을 적는 것으로 처리한다.

## 커버리지 공백

없음. 네 렌즈가 모두 결과를 돌려줬다. grounding 은 글자 수 계산(원칙 초안, 상시 보기, 리마인더)을 Bash 가 없어 확인하지 못했다고 적었다.

## 처분

`🔴` 없음. 되돌리기 어려운 결정(push·배포)은 spec 이 이미 사용자 지시 때만 하도록 두었고, 고치는 방향이 갈리는 지적도 근거로 고를 수 있었다. 나머지는 모두 고친다.
