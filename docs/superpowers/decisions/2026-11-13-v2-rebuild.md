# v2 재건축 채택과 11-13 기록 정정

disciplined-coder 를 v2 로 다시 짓기로 했다. 같은 날 쓴 결정 기록 `2026-11-13-prompting-guide-clauses.md` 의 「함께 닫은 항목」은 근거가 틀려 이 기록에서 정정한다. 그 기록은 봉인되어 고칠 수 없다.

## 결정

v2 재건축을 채택한다. 설계는 `docs/superpowers/specs/2026-11-13-v2-rebuild-design.md` 이고, 렌즈 리뷰 기록은 spec 이 `docs/superpowers/reviews/2026-11-13-v2-rebuild-review.md`, 0~3단계 plan 이 `docs/superpowers/reviews/2026-11-13-v2-rebuild-review-2.md` 다. 기준 버전은 v2 코드 변경 전 커밋에 단 로컬 태그 `archive/v1-final` 이다.

2026-11-13 사용자가 계획 전체 비용 50~80달러를 듣고 "전부 진행하자"로 승인했다. 이 승인으로 2026-10-18 사용자 지시(원칙 전체를 한꺼번에 실은 묶음 비교 금지)를 거둔다. v2 는 현행과 새 버전을 실제 대화 재현으로 비교하고, 당시 금지 이유였던 위반 수의 흔들림은 순서 교차 개선 점수·숨긴 턴 120개·부호 검정으로 다룬다.

재건축의 근거 측정은 spec 「목적」에 있다.

1. 실제 메시지 29개에서 원칙·금지어 목록·리마인더를 모두 뺀 답이 현행 답보다 개선 점수 평균 +0.14 였다(개선 14, 악화 11, 같음 4, 한쪽 부호 검정 p=0.35). 현행 원칙은 답 형태에 효과가 거의 없다.
2. "지시면 실행하고 결과만, 질문이면 물은 것만 답하라" 조항과 매 턴 리마인더 한 줄을 추가하면 같은 29개 중 20개가 나아지고 3개가 나빠졌다(평균 +0.57, p=0.0002). 답 길이 중간값은 880자에서 713자로 줄었다.
3. 110턴 배치 시험을 보정 판정자로 다시 판정하니 지금 리마인더는 위반을 48건에서 43건으로 줄였고, 이 차이는 유의하지 않다.

## 정정

`2026-11-13-prompting-guide-clauses.md` 「함께 닫은 항목」의 정정 내용은 세 가지다.

첫째, 그 절은 2026-11-11 조항 분류를 닫았다고 적었다. 그 근거는 보정 전 판정자의 결과라 이 문장은 틀렸다.

둘째, 보정 판정자로 다시 판정한 110턴 결과는 지금 리마인더 위반 48건→43건(유의하지 않음)이다. 리마인더 후보 줄마다의 고쳐짐·나빠짐 턴 수는 아래와 같다.

| 후보 줄 | 고쳐짐 | 나빠짐 |
|---|---|---|
| 결정 질문 | 3 | 0 |
| 요청한 변경만 | 3 | 0 |
| 확인 안 한 상태를 사실처럼 쓰지 않기 | 2 | 0 |
| 압축하지 않기 | 2 | 0 |
| 지시에 없는 파일까지 먼저 확인 | 0 | 2 |
| 직역투 | 0 | 1 |

셋째, 조항 분류 작업은 따로 하지 않고 v2 재건축이 대신한다.

같은 절이 함께 닫은 "가이드 후보 R01~R13"과 "compact 직후 리마인더를 닫는다"도 보정 전 판정이나 측정 없이 닫은 항목이다. compact 직후 리마인더는 매 턴 리마인더가 compact 뒤에도 메시지마다 실리므로 따로 장치를 두지 않고, 실제 세션에서 compact 직후 위반이 관찰되면 다시 연다(spec 「측정으로 Claude 가 정할 쟁점」 6).

## 다음 단계

0~3단계 plan 은 `docs/superpowers/plans/2026-11-13-v2-rebuild-stage0-3.md` 다. 3단계 검증은 spec 「시험 체계」의 채택 규칙을 따른다. 숨긴 세트에서 개선 턴이 악화 턴보다 많고 한쪽 부호 검정 p<0.05 이며, 지적 없던 턴에서 악화가 개선 이하이고, 사용자 판독의 과반이 같거나 나아야 채택한다. 첫 시험이 미달하면 문구를 한 번 고쳐 겹치지 않는 새 숨긴 세트로 다시 시험하고, 두 번 미달하면 4~7단계를 진행하지 않고 멈춰 사용자에게 결과를 보고한다.
