# 미병합 워크트리·브랜치 작업의 처분

2026-11-13 에 사용자가 미병합 작업을 모두 가져오되, 의도와 충돌을 파악하고 쓸모없는 것은 버리라고 지시했다("응 다 가져와 권한 승인해줄께"). Claude 가 출처마다 의도를 확인하고 아래처럼 처분했다. 판단 기준은 11-12 줄인 원칙(`2026-11-12-principles-lite.md`)과 맞는지, 사용자 결정이 있는지, 공개 저장소에 올려도 되는지다.

세 출처의 원본은 보존 태그로 고정했으므로 워크트리와 브랜치를 지워도 잃지 않는다. 태그는 `archive/2026-11-13-managing-docs-agent-uncommitted`(미커밋 작업의 스냅숏 커밋), `archive/2026-11-13-agent-a600`, `archive/2026-11-13-usability-research` 다.

## managing-docs-agent 워크트리 (11-02~11-04, 미커밋)

그 세션은 콘솔 답변 교정 mod 를 설계하다 사용자 지시로 보류했고, 이어서 조항 문구를 8개 방식으로 비교하는 시험(환산 143.61달러)과 원칙 재작성을 했다. 재작성은 사용자의 diff 검토를 기다리던 상태였다.

## origin/claude/plugin-combination-research-vd1129 (10-24, 커밋 1개)

클라우드 세션이 플러그인 조합(기본·dc·superpowers·둘 다)의 사무직 사용성을 비교하는 실행기와 과제 10개를 만들었다. 실행한 기록은 찾지 못했다.

실행기는 버렸다. 원칙 묶음 비교를 하지 않는다는 CLAUDE.md 결정과 충돌하고, 리눅스 클라우드용이라 이 PC 에서는 인증부터 실패하며, 11-11 spec 「남은 작업 처분」이 이미 쓰지 않기로 정했다.

과제 중 삭제 전 확인(t05), 비밀 노출(t08), 기술 질문 금지(t04)는 조항 시험 질문의 후보로 쓸 만하다. 그러나 새 시험 체계를 만드는 작업이라 지금 가져오지 않고 태그로만 보존한다. 표본 파일은 모두 지어낸 자료였다.
