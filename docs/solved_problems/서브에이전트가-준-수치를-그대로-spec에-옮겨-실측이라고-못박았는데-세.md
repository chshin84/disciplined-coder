# **서브에이전트가 준 수치를 그대로 spec에 옮겨 "실측"이라고 못박았는데 세어 보니 틀렸다.**

- 원인: 남의 스킬 규칙이 시험 문서에서 발동 문턱을 넘었다는 보고를 받아 그대로 설계 근거로 썼다. 그 서브에이전트가 규칙이 잡는 어미("~해야 한다")가 아니라 비슷한 다른 말("필요하다")을 센 것이었고, 문턱 5에 실제는 1이었다.
- 해결: 설계 문서에 수치를 적기 전에 그 값을 내가 직접 다시 낸다. 특히 "실측이다"·"확인했다"로 단정하려는 값은 반드시 그렇게 한다 — 리뷰어가 다시 재서 잡아 주기는 하지만, 그때는 이미 그 값 위에 결론이 쌓인 뒤다.
