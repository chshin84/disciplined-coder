# **목적이 다른 남의 도구는 참조만 해도 그쪽 판정 기준이 딸려 온다.**

- 원인: 한국어 문체 스킬의 패턴 목록을 "베끼지 말고 링크한다"로 들이려 했다. 그런데 그쪽 목적은 "AI가 쓴 티를 지운다"이고 우리는 "전달을 방해하는 것을 줄인다"라, 같은 항목에서 처방이 갈렸다 — 문두 접속사를 그쪽은 빼라 하고 우리는 넣으라 한다.
- 해결: 외부 목록을 들일지 정할 때 항목이 겹치는지 보지 말고 **목적이 같은지**를 먼저 본다. 목적이 다르면 링크도 걸지 않는다. 그리고 우리가 고정 목록을 안 만들기로 했다면 겹침을 따질 이유 자체가 없다 — 겹침 비교에 들어간 순간 설계를 스스로 배반한 것이다.
