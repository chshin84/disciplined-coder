# 이 레포의 check 에 명령을 넣을 때는 달러 괄호를 역슬래시로 escape 해 지연시키고, 새 검사는 반드시 실패를 한 번 보고 나서 통과시킨다.

- 증상: 훅 넛지 제외를 검사하는 줄을 새로 넣었는데 고치기도 전에 통과했다.
- 원인: check 는 문자열을 받아 나중에 eval 하는데, 내가 쓴 줄은 명령 치환을 escape 하지 않아 정의 시점에 평가됐다. 그 값이 빈 문자열이라 단언이 무조건 참이 됐다.
- 해결: 옆의 기존 check 줄과 모양을 그대로 맞춰라 — 지연시킬 것은 역슬래시 달러 괄호이고, 픽스처를 만드는 헬퍼만 지금 평가한다. 그리고 새 검사는 대상을 고치기 전에 돌려 실제로 FAIL 이 뜨는지 먼저 보라.
